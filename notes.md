# Notes
git status: sirve para ver las ultimas modificaciones que se hicieron y ver que se tiene que hacer 
git add: Para juntar lo cambios que se van a hacer committed
git commit: va aguardarl los cambios de lo que se añadio con add
git push: sube todo el commit a github
git branch <Nombre>: Para añadir una nueva rama que no modifique la principal 
git branch -D <Nombre>: Elimina una rama
git branch: Enlista las ramas existentes 
comando -h: nos dice lo que se puede hacer con ese comando 

git checkout: sirve para intercambiar ramas o commits 
git switch: Para cambiar de rama 

git commit: guarda los cambios del staging area
